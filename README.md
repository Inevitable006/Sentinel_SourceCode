# Sentinel_SourceCode

## Setup

To set up the models required for Sentinel, run the download scripts in the `backend/scripts` directory:
- 1.5B MS Model: `python backend/scripts/download_model_1_5b_ms.py`
- 7B HF Model: `python backend/scripts/download_model_7b_hf.py`

This will download the required `*.gguf` files and place them in the `backend/models` directory.

# What Sentinel can do (tested snapshot, 2026-10-17)

The single authoritative list. "Works" means exercised by automated tests on this snapshot; anything needing hardware, model files or a manual check says so. Not listed = not implemented.

| Area | State | Notes |
| --- | --- | --- |
| Typed local chat | Works | Real Qwen 2.5 7B GPU chat smoke; correct chat template per model (ChatML for Qwen, Llama 3 format for Llama); instructions always present, memories added as untrusted data. |
| Tool approvals | Works | Every model tool call needs approval; Tier 3+ needs a fresh PIN; single-use tokens are atomic; failures are reported as failures. |
| Cancellation | Works | Stop cancels the request's own processes and network calls, including approved actions. |
| Workspace | Works | Tasks with reminders, plans (step-by-step approval, interruption recovery), email/calendar/document drafts (never sent), memory, history with "continue conversation", privacy view, skill switches, emergency stop. |
| Python coding skill | Works, contained | Separate isolated process, job-object memory cap, no network/processes/native code, files only in the Sentinel Python workspace, 20 s limit. Not a sandbox for hostile code. |
| Coding | Works | In Sentinel Workspace: list, search, read, outline (function/class skeleton), stats (file/line/function/class counts), imports (dependency listing) and references (symbol usage search) for code (Tier 2); run a project's unittest tests in the contained runner limited to that project folder (Tier 3, PIN); change code via file actions (preview + undo). |
| Blender skill | Unavailable | Blender cannot be contained the same way; calls fail with an error. |
| Research/writing pack | Works, mechanical checks | In chat: prepare report/article/email briefs, then review supplied draft text for word limits, TODO/TBD/FIXME markers, and missing, empty, duplicate or unused numbered references. Uses `[1]` citations with a separate `[1]: source title — URL or document/page` line. Existing search/document tools collect material; existing Workspace Documents or approved file actions save drafts. No factual/source verification, automatic research, sending or publishing. |
| Business/marketing pack | Works, supplied assumptions | Contribution margin, break-even and target-profit units, revenue/cost/profit calculations; click-through funnel CTR, conversion rate, CPC/CPA/CPM and ROAS. Consistent currency/period required. Zero denominators return undefined, nonpositive margins do not produce fictitious break-even estimates. No campaign execution or market forecasting. |
| Technical pack | Works, deterministic | Compatible length/mass/time/data/temperature/energy/power conversions and transfer-time estimates. Distinguishes bits/bytes and decimal/binary units; rejects incompatible units and below-absolute-zero temperatures. No live speed testing or engineering certification. |
| Scheduled plans | Works, approval required | Optional ready-for-review time in Workspace Plans. Waits for both due time and available resources; every action still needs approval. Cancellation never releases the plan. Status refreshes while viewing the workspace. |
| Battery / GPU heat | Works when sensors available | Unplugged battery at or below 15% pauses heavy work; GPU temperature at or above 85°C triggers the sustained emergency path. Existing clean-reading recovery applies. Missing sensors stay unknown. Full-screen/call detection and CPU thermal readings are not implemented. |
| Gmail / Google Calendar | Implemented; live consent unverified | Settings imports a Desktop OAuth client, creates PKCE/state-protected loopback sign-in and stores tokens in the encrypted vault. Explicit Refresh shows up to 10 inbox previews or 25 events in the next seven days. Read-only grants, no automatic sync/send/event writes. Offline mode and lock/disconnect cancellation tested with mocked Google traffic. Owner must enable both APIs and authorize their account. |
| Web research / finance quote | Works (network) | Through the egress guard; connections pinned to the validated address; 2 MB response limit. |
| File actions | Works | Create, edit, move, delete inside Documents\Sentinel Workspace only (SENTINEL_FILES to change). Preview on the approval card, refused if the file changed after approval, Undo for 5 minutes (Workspace → File actions), then final. Deleted files are held until the window closes. |
| Document reading | Works | Text, CSV, JSON, Markdown, Word (.docx), Excel (.xlsx) and PDF from the project, Sentinel data folder or Sentinel Workspace; no new packages; oversized/zip-bomb/unsafe-XML files refused. PDF text (up to 50 pages, pypdf 5.4.0); scanned PDFs without text and old .doc/.xls not yet. |
| Image analysis | Works (slow, CPU) | Attach an image in chat: validated, kept in memory, analyzed by local LLaVA 1.5 7B (files pinned by SHA-256 in backend/vision-model.json, stored in %APPDATA%\sentinel\models\llava). About 30–60 s per image on CPU. |
| Dictation | Works | Local Whisper base (CPU), all model files pinned and verified; real offline synthetic test passes. Microphone quality not yet tested by the owner. |
| Speech output | Works, not heard in tests | Choose a male or female Windows voice (David / Zira on this PC) and speed in Settings → Voice, with Preview; saved for next time. Stops on lock, emergency stop and Voice off. |
| Portfolio Advisor | Works (advice only) | Import holdings (Zerodha/Groww/CAMS CSV) or add by hand; value, gain, mix, true yearly return (XIRR) from your transactions (add by hand or import a statement CSV; duplicates skipped); fund NAVs (AMFI) and NSE prices when you press Refresh; suggestions with reasons and steps; SIP/lumpsum ranges; ask about it in chat. Capital-gains tax estimate (India, rules in backend/tax-rules-in.json): this year's realised gains by type, FIFO matching, ₹1.25 lakh LTCG exemption left, 'if you sold today', tax-free harvesting hint. Estimate only. Fund costs: enter each fund's expense ratio (no reliable free bulk source exists); shows yearly cost, 10-year cost, high-cost flags, Direct-plan savings, and same-type-fund overlap hints (name-based). Never logs in or trades. |
| Daily briefing | Works | "Today" screen (opens first): reminders due today (local time) and overdue, plans needing you, portfolio change since the previous price refresh, PC health, backup age; Read aloud. Read-only. |
| Encrypted backup | Works | Settings → Backup: one .sentinelbak file, still encrypted; opens with your PIN on this PC or your recovery key anywhere. Restore from the lock screen: checked first, current data kept aside. Last 5 kept locally. |
| System Watch | Works | Every 15 min + Check now: startup items, scheduled tasks, services, admin accounts, firewall, Defender and threats, programs running from Downloads/Temp, Sentinel's own files. Alerts with steps; only automatic reaction is Offline mode on a critical alert. Not an antivirus. |
| What Sentinel did | Works | Security → What Sentinel did: every action in plain words (from chat/plan, approved or not, done/failed/blocked), filters, last 1/7/30 days, plus the audit-log integrity check. No search terms or file contents recorded. |
| Lock | Works | Manual, idle timeout, Windows lock and sleep (Electron powerMonitor; manual check recommended). UI hides data when lock state cannot be confirmed. |
| Skill limits | Works | Each skill has an hourly limit (web 20, finance 30, Python 20, files 30, system 30, Blender 10; read-only skills none). Over the limit, requests are refused before approval with how long to wait. Change in Security → Skills (PIN). Counters reset on restart. |
| Skill integrity | Works | Pinned SHA-256 per built-in skill checked at registration and load; development mode only with SENTINEL_SKILL_DEV=1. Re-pin with `tools/pin_skills.py`. |
| Audit log | Works | HMAC-chained entries (DPAPI-protected key), tamper detection, 5 MB rotation, sanitized errors. Detects tampering; cannot prevent it by a process running as you. |
| Installer | Built; clean-machine install unverified | Portable runtime imports the current backend and registers all 14 skills. `npm run dist` builds the Windows installer under `dist/`. A clean-machine install and first-run hardware checks remain owner verification steps. |

Not implemented (from the NEXUS idea): biometrics/Windows Hello, wake word, vector memory, multi-user, cross-device sync, creative media, health, OS-wide security monitoring.

Full-screen/presentation pauses use the Windows shell notification-state signal (busy, exclusive Direct3D, presentation). Two consecutive polls pause the model and scheduled plans; three clear polls permit recovery. This does not identify calls or guarantee detection of every borderless game. No screen contents or window titles are read. Reference: https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ne-shellapi-query_user_notification_state
